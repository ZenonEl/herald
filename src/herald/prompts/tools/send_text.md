Send a free-form formatted message with provenance metadata.

Call get_writing_rules(project) before composing. HTML is the default.
Use raw Telegram tags: <b>, <i>, <u>, <s>, <code>, <pre>, <blockquote>,
<blockquote expandable>, <tg-spoiler>, and <a href="...">.
Never encode tags as &lt;b&gt;. Escape literal text characters instead.
The preset describes editorial density; this tool has no field or word budget.
Plain and HTML text with the generated signature must fit 4096 visible characters.
For native Telegram tables, headings and other rich blocks, use format=rich_markdown
with Markdown source (not MarkdownV2). Source limit: 32768 characters including provenance.

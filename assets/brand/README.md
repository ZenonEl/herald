# Herald brand assets

Herald uses a winged terminal bird: a local AI command becomes a delivered
message. The mark does not copy Telegram's paper-plane symbol.

## Palette

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#182033` | Primary text and Herald context |
| Signal cyan | `#177f83` | Incoming message and route |
| Delivery coral | `#c95d45` | Approved destination and emphasis |
| Paper | `#f3eee4` | Editorial background |
| Slate | `#596170` | Secondary text |

Keep clear space around the mark equal to one quarter of its width.
`herald-bird.png` is the approved primary mark; preserve its proportions and
add padding rather than redrawing it for square avatars.

`herald-social-preview.png` is the approved 1280×640 file prepared for GitHub's
Social preview setting. Editable production sources are kept outside the public
release tree.

The frame presents Herald as an adapter-oriented communication layer. Telegram
is its first and currently only transport; Watch remains a secondary capability.

# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [0.4.0] — 2026-08-14

### Добавлено

- точная фильтрация захвата по Telegram forum topic;
- несколько топиков одной группы с отдельными slug;
- структурированный `reply_context`: родитель, точная цитата и внешний ответ;
- backfill непосредственного родителя и его вложения при новом ответе;
- совместимая миграция существующей SQLite-базы.

### Безопасность

- полный контекст родителя сохраняется только для разрешённых capture-target;
- из незарегистрированного топика остаётся только явно показанная цитата.

## [0.3.0] — 2026-08-13

### Добавлено

- первый публичный выпуск Herald;
- MCP-отправка текста и файлов в Telegram;
- пресеты сообщений и глобальный skill для ассистентов;
- локальный capture-буфер и экспорт для Mnemo;
- двойное лицензирование AGPL-3.0-or-later и CC BY-SA 4.0.
